# YouTube → MP3 для мини.автора

Отдельный Vercel проект. Принимает запрос только от основного бота, скачивает одно видео YouTube до 10 минут, делает MP3 192 кбит/с, оценивает BPM и тональность по звуку и отправляет аудио прямо в Telegram. Оценка может ошибаться, особенно на битах без выраженной гармонии или с половинным/двойным темпом.

## Деплой

1. Создай отдельный проект Vercel с **Root Directory** `mp3-worker`. Если деплоишь через CLI, запусти `vercel --prod` из этой папки и выбери новый проект.
   Стандартная точка входа находится в `app.py`, а `pyproject.toml` задаёт `app:app` и все Python-зависимости; оба файла должны входить в коммит при деплое через GitHub.
2. В настройках нового проекта добавь переменные:
   - `TELEGRAM_BOT_TOKEN` — тот же токен, что у основного бота;
   - `MP3_WORKER_SECRET` — новая случайная длинная строка. Не используй `WEBHOOK_SECRET`.
3. В настройках проекта включи **Fluid Compute**. Функция `/api/convert` настроена на 300 секунд.
4. После деплоя проверь адрес `https://<домен-воркера>/api/convert`. Запрос GET может вернуть 501; это нормально: рабочий метод POST защищён секретом.
5. В **основном** проекте Vercel добавь:
   - `MP3_WORKER_URL=https://<домен-воркера>/api/convert`;
   - `MP3_WORKER_SECRET` — та же строка, что в воркере.
6. Передеплой основной проект. Его вебхук настроен на 300 секунд, чтобы фоновый вызов воркера не оборвался после быстрого ответа Telegram.
7. Открой бота, отправь `/start` (обновит список команд), затем `/beat https://youtu.be/<ID>` или нажми «🎧 Скачать биток» в меню и пришли ссылку.

Если `vercel` не установлен, можно запустить `npx vercel --prod`. Токены вводи только в настройках проектов Vercel, не записывай в файлы репозитория.

Для отправки используется Telegram Bot API, поэтому MP3 ограничен 49 МБ. Некоторые видео YouTube могут не скачаться из-за ограничений площадки. Используй материалы, на которые у тебя есть право скачивания.
