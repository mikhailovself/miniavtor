# Бот «мини.автор» для Telegram

Telegram-бот на Vercel (Node/TypeScript, вебхук). Три роли:

1. **Секретарь.** Пишешь в личку, нейросеть выбирает топик твоей группы и публикует там оформленную заметку.
2. **Собеседник.** В личке и в обычных группах общается в образе «мини.автора»: коротко, грубо, с матом и подъёбками.
3. **Набор инструментов.** MP3 с BPM и тональностью из YouTube, кружки из видео, гифки, определение BPM по файлу.

У каждого пользователя своя группа с топиками. Ключи нейросетей общие (владельца), поэтому есть дневной лимит на человека.

## Стек

| Что | Чем |
|---|---|
| Хостинг, cron | Vercel (serverless-функция `api/webhook.ts`) |
| Бот | Telegram Bot API, вебхук |
| Нейросети | Gemini API + резерв в формате OpenAI (Groq, Mistral, Cerebras, OpenRouter, DeepSeek) |
| База | Upstash Redis (REST) |
| Гифки | API gifka.me |
| MP3, BPM, тональность | отдельный воркер `mp3-worker` (Python, librosa), вызывается по HTTP |
| Кружки | `ffmpeg-static` внутри функции Vercel |
| Название ролика | YouTube oEmbed (без ключа) |
| Логи диалогов | второй бот (`LOG_BOT_TOKEN`) |

### Файлы проекта

Папка `api/` содержит только `webhook.ts` (вся основная логика): на Hobby-плане Vercel максимум 12 функций, а каждый файл в `api/` считается отдельной функцией. Хелперы лежат в `lib/`: `notes.ts` (оформление и правка заметок), `group-chat.ts` (история группы, обида, действия по просьбе), `friends.ts` (справочник знакомых), `roast.ts` и `roast-gate.ts` (жёсткие подъёбки), `gifka.ts`, `animated-emoji.ts`, `emoji-candidates.ts`, `subscription.ts`. Конвертер лежит отдельно: `mp3-worker/api/convert.py`. Для кружков в `vercel.json` нужен `includeFiles: node_modules/ffmpeg-static/**`, пакет `ffmpeg-static` указан в `package.json`.

## Нейросети

**Порядок вызова:** `Gemini` (основная) → `Gemini Lite` (запасная) → `LLM2` → `LLM3` → `LLM4`. Первый ответивший побеждает. Провайдеры, которые недавно падали, пробуются в последнюю очередь.

| Провайдер | Модель по умолчанию | Переменная |
|---|---|---|
| Gemini | `gemini-3.8-flash` | `GEMINI_MODEL` |
| Gemini Lite | `gemini-3.5-flash-lite` | `GEMINI_FALLBACK_MODEL` |
| LLM2–LLM4 | любая из списка провайдера | `LLMN_NAME`, `LLMN_BASE_URL`, `LLMN_API_KEY`, `LLMN_MODEL` |

Обе Gemini работают через один `GEMINI_API_KEY`. Бесплатные лимиты Gemini считаются отдельно по каждой модели, поэтому, когда у основной кончились запросы, Lite отвечает со своим запасом. Если `GEMINI_FALLBACK_MODEL` совпадает с `GEMINI_MODEL`, запасная не добавляется.

**Пауза после ошибки** (хранится в Redis, чтобы не ждать упавшую модель зря): 429 (лимит) — 2 минуты, 401/403/404 (ключ или модель) — 1 час, остальное — 1 минута.

**Параметры запроса:**
- Температура: 0.9, если доступно сохранение заметок (важна точность имён и сумм), иначе 1.1 для болтовни. У Gemini дополнительно `topP 0.95`.
- Таймаут: Gemini 11 с на текст и 18 с на запрос с медиа; резервные LLM 9 с. Новая попытка у следующего провайдера не начинается, если прошло больше 16 с (10 с с медиа).
- Фильтры Gemini: `HARASSMENT` отключён (иначе грубые ответы режутся), `SEXUALLY_EXPLICIT` на `BLOCK_ONLY_HIGH`.
- Функции модели: `save_note`, `update_note`, `chat_reply`, `ask_owner`, а в группах ещё действия по просьбе (стикер, мем, гифка, реакция, запомнить, забыть, пост из канала).

**Ограничения:**
- Фото, голосовые и кружки понимает только Gemini; резервные LLM их не получают. Лимиты вложений: фото 5 МБ, голос 6 МБ и 120 с, кружок 8 МБ и 45 с.
- Резервная модель должна поддерживать tool calling (бот требует вызова функции).
- На бесплатном тарифе Google, по его условиям, может использовать запросы для улучшения моделей. Бот отправляет туда личные переписки, анкеты и заметки. Если это неприемлемо, привяжи биллинг к проекту Google.
- Если не ответила ни одна модель, пользователь получает сообщение о недоступности нейросетей, а владелец в личку подробности по каждой (не чаще раза в 10 минут).

## Характер бота

Единая персона собрана из блоков в `api/webhook.ts`:

| Блок | Назначение |
|---|---|
| `VLAD_CHAT_PERSONA` | базовая манера речи, склеена из `_BASE` и `_BOOST` |
| `VLAD_CHAT_PERSONA_BOOST` | усиление: разбор слов собеседника, грубость без смягчений, короткие острые реплики, границы |
| `VLAD_LORE` | кто такой бот, близкий круг, публичные ссылки |
| `VLAD_VIEWS` | взгляды и интересы |
| `ROAST_ENGINE` (`lib/roast.ts`) | жёсткие подъёбки, включаются после третьего подряд оскорбления бота |
| `TEXT_STYLE_RULE` | единый голос всех текстов бота |
| `NOTE_STYLE` | заметки пишутся аккуратно, без мата и опечаток |
| `GROUP_RULES` | поведение в групповом чате |

**Что остаётся всегда:** никаких оскорблений групп людей, реальных угроз и травли, личные данные не выдаются, пошлости с несовершеннолетними нет. Если человеку плохо или он просит серьёзной помощи, грубость выключается. На серьёзный вопрос «ты бот?» бот отвечает честно.

Часовой пояс один для всех: Москва (`DEFAULT_TZ`).

## Запуск

1. **Бот.** @BotFather → `/newbot` → токен.
2. **Репозиторий и Vercel.** Залей файлы в GitHub (код в папке `api`), подключи проект к Vercel.
3. **База.** Vercel → Storage → Upstash Redis (бесплатный план), привяжи к проекту. Без базы бот работает только как «не настроен».
4. **Переменные** (Settings → Environment Variables).
5. **Redeploy.**
6. **Вебхук.** Открой в браузере (подставь токен, адрес и секрет):
   `https://api.telegram.org/botТОКЕН/setWebhook?url=https://ПРОЕКТ.vercel.app/api/webhook&secret_token=СЕКРЕТ`
7. **Старт.** Напиши боту `/start`. Затем в админке «Система» → «Вебхук» → «Включить нужные обновления» (или `/webhookfix`): это выставит нужный `allowed_updates`.

### Переменные окружения

| Переменная | Нужна | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен бота |
| `WEBHOOK_SECRET` | да | секрет вебхука |
| `CRON_SECRET` | да | без него ежедневный cron отвечает 503 |
| `GEMINI_API_KEY` | да | ключ Gemini (общий для основной и запасной модели) |
| `OWNER_ID` | да | Telegram ID владельца: админка, без лимитов |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | да | подставляет Vercel при подключении Redis (подходят и `KV_REST_API_*`) |
| `GEMINI_MODEL` | нет | основная модель, по умолчанию `gemini-3.8-flash`. Если переменная уже задана в Vercel, она перебивает значение по умолчанию |
| `GEMINI_FALLBACK_MODEL` | нет | запасная модель, по умолчанию `gemini-3.5-flash-lite` |
| `LLM2_*`, `LLM3_*`, `LLM4_*` | нет | резервные нейросети (см. выше) |
| `DAILY_LIMIT` | нет | запросов к нейросети на человека в сутки, по умолчанию 60, `0` — без лимита |
| `CHATTER_CHANCE` | нет | шанс самопроизвольного ответа в группе без тем (0–1), по умолчанию `0.04` |
| `MEME_CHANNEL` | нет | канал-источник мемов (юзернейм или id), по умолчанию `vladavtorx` |
| `BOT_USERNAME` | нет | юзернейм бота без @, иначе бот узнает его сам |
| `MP3_WORKER_URL`, `MP3_WORKER_SECRET` | для битков и BPM | адрес и секрет воркера; без них бот пишет, что конвертация не настроена |
| `GIFKA_API_KEY` | нет | ключ gifka.me, если нужен |
| `LOG_BOT_TOKEN` | нет | токен второго бота для журнала диалогов; владелец должен нажать у него `/start` |
| `GROUP_CHAT_ID` | нет | нужен только при переносе данных из старой версии |

Обновление со старой версии (один пользователь): при первом сообщении от `OWNER_ID` бот один раз переносит группу, топики, подсказки и запасной топик из ключей `tg:*` в новую схему.

## Как пользоваться

### Подписка

В личке бот проверяет подписку на `@vladavtorx` (бот должен быть администратором канала, иначе проверка неполная). Неподписанный человек после `/start` видит ссылку и кнопку «Проверить подписку», остальное игнорируется. Проверка действует и в inline-режиме. В группах подписка не нужна. Если проверить не удалось, доступ временно закрыт.

### Секретарь: подключение группы

1. Создай группу и включи **Темы** (до добавления бота: при включении тем меняется внутренний номер группы).
2. Создай топики («Покупки», «Идеи», «Фильмы», «Долги»). Названия любые, бот выбирает по смыслу.
3. Добавь бота в группу админом (иначе он не видит сообщения в топиках).
4. Админ группы пишет `/connect`.
5. В каждом топике напиши любое сообщение или `/ids` (один раз на топик, новые бот подхватывает сам).
6. Пиши заметки боту в личку.

Одна группа на одного пользователя; при подключении другой старая отвязывается. Настройки топиков меняет только подключивший. Остальные участники группы видят заметки. Если группа стала супергруппой, подключение переносится само. Если бота выгнали, подключение сбрасывается, владельцу приходит уведомление.

Команды в топике (только у подключившего): `/ids`, `/desc текст` (подсказка, что сюда класть), `/default` (запасной топик для всего, что некуда деть), `/forget`, `/disconnect`. Тот же набор доступен кнопками: «🗂 автор.секретарь» → «📚 Мои топики».

### Заметки

- **Что можно написать:** текст, ссылку, фото, скриншот, голосовое или кружок. Если во вложении есть что запомнить (афиша, чек, список, адрес), бот делает заметку, иначе просто отвечает. К заметке из фото прикладывается сама картинка. Ссылка с просьбой сохранить добавляется в заметку, видео с такой подписью бот пытается скопировать в топик.
- **Оформление:** заголовок, эмодзи, короткий текст (только то, чего нет в заголовке), теги по просьбе, срок, поля долга (кто, сколько, направление). Повторы чистит код (`cleanNote` в `notes.ts`).
- **Дополнение вместо дубля:** если речь о том, что уже записано (фильм, покупка, человек), бот дописывает новые факты в ту же заметку. Если модель всё же создала дубль, код находит похожую заметку в том же топике (обычные не старше 14 дней, списки без срока) и дополняет её. Долги и заметки с разными сроками не склеиваются.
- **Списки:** «составь список покупок: молоко, хлеб» создаёт одну заметку с пунктами `⬜`. «Добавь сыр» дописывает, «купил хлеб» отмечает `✅`, «убери кофе» удаляет пункт, «очисти купленное» убирает отмеченные. Пункты можно отмечать кнопками под заметкой (только подключивший группу). Это кнопки бота, а не чек-листы Telegram.
- **Правка:** «Саша вернул 500, осталось 1500», «Дюну посмотрел», «исправь текст заметки про билеты», «перенеси в другой топик», «удали заметку». Можно ответить реплаем на заметку прямо в группе. Закрытый долг удаляется, а если Telegram не даёт удалить, помечается закрытым. При неоднозначности бот переспрашивает.
- **Поиск:** «найди Дюна», «найди кому я должен».
- **Отмена:** «верни как было» отменяет последнюю правку или восстанавливает удалённую текстовую заметку новым сообщением. Снимок хранится сутки; фото, видео и переносы не восстанавливаются.
- **Лимиты:** в индексе 100 последних заметок на пользователя, для правок модели видны последние 40. Сообщение Telegram до 4096 символов, подпись к медиа до 1024; слишком длинную заметку бот не дописывает и просит разделить. Заметки, опубликованные до появления индекса, не меняются.
- **Защита от дублей:** создание заметок идемпотентно в течение 7 дней. Если Telegram мог принять сообщение, а ответ не сохранился, бот сообщает, что доставка не подтверждена, и повторно не отправляет. Остальные действия бота такой защиты не имеют.

### Напоминания

Если у заметки есть срок, бот пишет в личку за день до срока и в день срока. Напоминание «на сегодня» создать нельзя: бот отвечает отдельным текстом. Прошедшие даты и даты дальше чем через год отклоняются. Проверка идёт один раз в день через cron `0 6 * * *` (около 09:00 МСК) на `/api/webhook?cron=1`; на плане Hobby чаще нельзя. Неотправленное остаётся в очереди. Выключить: «⚙️ Для себя» → «Напоминания».

### Инструменты (`/tools`)

- **🎶 Скачать биток** (`/beat` или `/beat_avtor`). Ссылка на ролик YouTube (watch, youtu.be, shorts, live, music). Бот присылает MP3 с названием, BPM и тональностью; конвертирует воркер. Прогресс показывается полоской `🟩⬜` (проценты примерные, ползут по времени).
- **🎚 BPM и тональность** (`/bpm_avtor`). Работает по ссылке YouTube или по аудиофайлу (отправить файл с подписью-командой, ответить командой на трек или после команды скинуть бит). Файл до 20 МБ.
- **🎞 Сделать кружок** (`/circle`). Видео, GIF или видеофайл до 20 МБ. Бот берёт центр кадра, 384×384, до 60 с, 30 кадров/с, ffmpeg внутри функции, файл нигде не хранится. Лучше слать видео в 480p. Таймауты: скачивание и отправка по 8 с, ffmpeg 15 с.
- **🖼 Гифки** (`/gif_avtor запрос`). Кнопка открывает поиск gifka.me в текущем чате. Если Telegram не принимает ссылку на MP4, бот скачивает файл (до 10 МБ, 15 с) и отправляет сам, один раз.
- **💡 Чё добавить?** Свободное пожелание одним сообщением, приходит владельцу и сохраняется (последние 200). Выход: `/cancel`.

Команды `/gif_avtor`, `/beat_avtor`, `/bpm_avtor` работают в личке и в любой группе. Пауза на человека в чате: гифки 10 с, остальные 60 с.

**Inline-режим** (`@бот запрос` в любом чате): гифки на выбор, а по ссылке YouTube результат BPM и тональности дописывается в отправленное сообщение. Включается в @BotFather: `/setinline` и `/setinlinefeedback` → Enabled, затем в админке обновить `allowed_updates`.

### Обычные группы (без тем)

Бот не секретарь, а участник чата.

- **Сам пишет** на редкие сообщения (шанс `CHATTER_CHANCE`, уровень активности группы меняет множитель), иногда вместо текста кидает мем, стикер, гифку или ставит эмодзи-реакцию (на медиа чаще). Может ответить по фото, голосовому и кружку. Иногда пересылает пост из канала.
- **Отвечает всегда**, если позвали (`@бот`, ответ на его сообщение, «мини.автор», «бот,») или упомянули Влада или автора: в группе бот уверен, что говорят про него.
- **Память чата:** видит последние сообщения группы, помнит «приколы» (фразы, на которые много отвечали со смехом), может в шутку вернуться к ним.
- **Обида:** после затяжного спора бот сливается и на время игнорирует человека или весь чат (игнор или негативная реакция); извинение снимает обиду. Если несколько человек подряд говорят «ты не прав», бот сначала упирается, потом признаёт ошибку.
- **Действия по просьбе:** стикер, мем, гифка, реакция, пост из канала, «запомни», «забудь», «спроси у Влада».
- **Память по просьбе:** «запомни, что ...» (с обращением к боту) сохраняет факт только для этой группы. `/memories` показывает факты, `/forgetmemory ID` удаляет свой (владелец может любой). В личке «запомни» создаёт личные факты. Хранится до 30 фактов, в контекст идут последние 20.
- **Знакомые:** справочник `friends.ts` (по Telegram ID, из экспорта общей группы) подстраивает обращение и манеру; с знакомыми бот может отвечать жёстче. Данные основаны на переписке 2023–2026 и могут устареть.
- **Лимиты:** между самопроизвольными сообщениями пауза, в сутки их не больше определённого числа (уровни ниже); на прямые обращения по умолчанию 60 ответов в сутки на группу, после лимита бот один раз об этом пишет.

| Уровень группы | Множитель шанса | Пауза | В сутки |
|---|---|---|---|
| Молчит | 0 | — | 0 (только если позвали) |
| Тихо | ×0.4 | 30 мин | 4 |
| Нормально (по умолчанию) | ×1 | 15 мин | 8 |
| Часто | ×2.5 | 5 мин | 20 |

Чтобы бот видел все сообщения группы, сделай его админом или выключи приватность: @BotFather → `/setprivacy` → Disable (после этого бота нужно удалить из группы и добавить заново). Фото чата бот запоминает отдельно для каждой группы (до 100) и иногда присылает их назад; отключается в настройках группы, запас при этом очищается. В группах с темами работают только заметки, без болтовни.

### Личные вбросы

Раз в несколько дней бот сам пишет тем, кто хотя бы раз открывал личку: короткая фраза, мем из запаса, ссылка на трек, вопрос по запомненной теме. Частота: выкл, 2, 3, 4 (по умолчанию), 5 или 7 дней ±1 день. В течение 12 часов после разговора вброс откладывается. Отключить: `/quiet`, вернуть: `/unquiet`.

### Анкета и передача Владу

- **«⚙️ Для себя» → «Рассказать о себе».** 11 вопросов (имя, музыка, игры, юмор, взгляды, личная жизнь и т.д.), любой можно пропустить. Ответы учитываются в личных и групповых разговорах, их можно посмотреть, обновить и удалить.
- **«Спроси у Влада», «передай Владу».** Владельцу приходит карточка, он отвечает реплаем, бот пересылает ответ как «Владос сказал: ...». Лимит 6 запросов в час на человека.

## Админ-панель (только `OWNER_ID`)

Кнопка «⚙️ Админ-панель» или `/admin`. Разделы:

- **🎛 Поведение:** частота ответов, частота мемов, пересылка постов канала, «интересные переписки», личные вбросы, лимиты (личка и обращения в группе).
- **👥 Люди и рассылка:** список пользователей (карточка, переписка, блокировка, ручной диалог), рассылка, «ответы мимо», группы и их активность, пожелания.
- **🖼 Мемы и канал:** загрузка мемов, источник канала.
- **🛠 Система:** сводка, нейросети, напоминания и cron, вебхук, проверка лог-бота.
- **🧪 Тесты функций:** тест подбора гифок gifka.me.

Подробности:

- **Нейросети:** по каждому провайдеру число удачных и неудачных вызовов за сегодня (включая группы) и пометка паузы. Токены, баланс и квоты провайдеров бот не получает, их смотри в кабинетах (для Gemini: AI Studio).
- **Переписка:** карточка пользователя → «💬 Переписка» показывает журнал личных реплик (до 200 на человека, 30 дней). Под ответами бота кнопка «👎 Ответ мимо»: до пяти последних неудачных ответов бот учитывает в разговоре с этим же человеком и не повторяет их формулировки (всего хранится до 100 примеров).
- **Ручной диалог:** «✍️ Подключиться к диалогу» в карточке. Автоответы этому человеку приостанавливаются, его сообщения приходят владельцу, а любое обычное сообщение владельца копируется человеку. Выход: кнопка или `/stoplive`, автоматически через 12 часов без активности. Подключиться можно только к одному человеку одновременно.
- **Рассылка:** владелец присылает сообщение, смотрит превью и число получателей (зарегистрированные пользователи, писавшие боту в личку; владелец и заблокированные исключены), подтверждает. Отправка идёт пачками, остаток подхватывает cron, есть повтор ошибок и остановка. `/quiet` рассылку не блокирует.
- **Интересные переписки:** нейросеть отмечает редкие яркие личные диалоги, бот присылает их владельцу с кнопками «Смешно / Мимо» (не чаще 4 в сутки, 1 в 30 минут, 1 на человека за 6 часов). Если оценок «мимо» больше, отбор строже.
- **Мемы:** запас хранится в Redis, пополняется из канала (источник `MEME_CHANNEL`, бот должен быть админом канала, нужен `channel_post`), пересылкой боту, режимом «Загрузить мемы» (фото, GIF, видео до 90 с, стикеры, ссылка на набор `t.me/addstickers/...`). Историю канала бот не читает, видит только новые посты. Если запас пуст, бот шлёт текст или гифку gifka.
- **Группы:** список групп без тем, активность каждой, пробный мем.

## Данные и приватность

В Redis хранятся: пользователи, группы и топики, настройки, счётчики, ID сообщений и `file_id` медиа (сами файлы остаются в Telegram), недавние заметки (для поиска и правок), сроки напоминаний, анкета, факты памяти, история диалога (10 реплик, сутки) и журнал личных реплик (200, 30 дней).

**Владелец видит личные переписки** (журнал в админке, а при заданном `LOG_BOT_TOKEN` и копии в лог-боте, плюс некоторые групповые диалоги с ботом). Новым собеседникам бот сообщает об этом после первого обычного сообщения. Лог-бот это текстовый журнал, а не полный архив: вложения помечаются меткой, часть служебных сообщений не записывается.

`/deleteme` (или «⚙️ Для себя» → «Удалить мои данные») стирает подключение группы, топики и подсказки, историю и журнал, анкету, личную память, расписание вбросов и напоминаний, примеры «ответов мимо». Заметки в самой группе остаются.

Основные ключи Redis:

| Ключ | Содержимое |
|---|---|
| `u:{uid}`, `g:{chat}`, `t:{chat}`, `d:{chat}`, `def:{chat}` | профиль, группа и владелец, топики, подсказки, запасной топик |
| `notes:{uid}`, `note:{uid}` | индекс и тела недавних заметок |
| `rem` | напоминания (ZSET по дате) |
| `h:{uid}`, `chatlog:{uid}` | короткая история, журнал личных реплик |
| `st:{uid}` | ожидаемый ввод (подсказка, биток, кружок, пожелание, анкета, рассылка) |
| `rl:{uid}:{день}` | дневной счётчик запросов к нейросети |
| `users`, `banned`, `memes`, `chats` | множества пользователей, банов, мемов, групп |
| `tg:cool:{провайдер}` | пауза после ошибки нейросети |
| `update:processing:ID`, `update:done:ID` | защита от повторной доставки обновлений |

## Лимиты и защита

- **Дневной лимит** на человека: по умолчанию 60 запросов к нейросети (UTC-сутки), у владельца нет. Считаются только сообщения, дошедшие до нейросети. Значения в админке: 0, 20, 40, 60, 100, 200.
- **Повторная доставка Telegram:** на время обработки ставится блокировка `update:processing` (330 с), успешное завершение запоминается на 7 дней. При исключении вебхук отвечает 503, чтобы Telegram повторил. Частично выполненные действия при повторе возможны.
- **Бан:** `/ban ID` или кнопка в карточке пользователя.
- **Cron:** защищён `CRON_SECRET`.
- Максимальное время функции задаётся в `vercel.json` (`maxDuration`).

## Как менять поведение

Всё в `api/webhook.ts`:

| Что менять | Где |
|---|---|
| выбор топика, дополнение, списки | `buildSystemPrompt` |
| оформление заметок | `NOTE_STYLE` и `lib/notes.ts` |
| манера, грубость, острота | `VLAD_CHAT_PERSONA_BASE`, `VLAD_CHAT_PERSONA_BOOST` |
| личность, ссылки | `VLAD_LORE` |
| взгляды | `VLAD_VIEWS` |
| группа | `GROUP_RULES` |
| голос всех текстов | `TEXT_STYLE_RULE` |
| список функций для нейросети | блок «ТВОИ ФУНКЦИИ» в `buildSystemPrompt` |
| модели, порядок, паузы | `getProviders`, `runLLM`, `coolDown` |
| температура | `genTemperature` |

Удачные примеры реплик в блок персоны действуют лучше, чем новые правила: берёшь реальные диалоги из админки и добавляешь 8–10 пар «человек → ответ».

**Новая функция.** Пройди чеклист в комментарии в начале `webhook.ts`: тексты в стиле бота, отдельный пункт в «Чё я умею?», пункт в «ТВОИ ФУНКЦИИ», команды (и версия `cmds:vN`), `/start`, лимиты, админка, очистка данных в `wipeUser`, состояния ввода (`st:`) и `/cancel`.

**Анимированные эмодзи.** Бот заменяет эмодзи в тексте, подписях и кнопках на проверенные анимированные custom emoji (`animated-emoji.ts`, кандидаты в `emoji-candidates.ts`, каталог кэшируется на 6 часов в Redis `ui:animated:v1:<BOT_ID>`). Статичные квадраты `🟩⬜` в прогресс-барах оставлены намеренно. Если нет ни одного проверенного значка, возникает `ANIMATED_EMOJI_UNAVAILABLE`, и меню может не отправиться. Для custom emoji боту нужны права Telegram (дополнительный username или Premium у владельца). Отображение на устройствах проверяется только в живом Telegram.

## Если что-то не работает

- **Общая диагностика:** Vercel → Logs; `https://api.telegram.org/botТОКЕН/getWebhookInfo` (поле `last_error_message`).
- **Молчит в личке:** проверь Redis (Storage), переменные, сделай Redeploy; если молчит только у тебя, проверь `OWNER_ID` и не забанил ли себя. Для неподписанных бот намеренно молчит, пока не нажато «Проверить подписку».
- **Отвечает только Lite или «нейросети недоступны»:** админка → Система → «Нейросети». Если у основной ошибки, проверь значение `GEMINI_MODEL` (после изменения переменной нужен Redeploy), точное имя модели в AI Studio и лимиты проекта. Ошибка 404 значит, что такой модели нет.
- **Резервная LLM не отвечает:** проверь `LLMN_BASE_URL`, ключ и что модель умеет tool calling.
- **`/connect` не отвечает:** бот не в группе или не админ, либо не включены темы.
- **Бот не видит сообщения в топиках:** сделай его админом группы.
- **Топики не запоминаются:** подключивший должен написать в топике любое сообщение или `/ids`.
- **Кнопки не нажимаются, inline не работает:** в `getWebhookInfo` проверь `allowed_updates`; нужны `message`, `callback_query`, `my_chat_member`, `channel_post`, `inline_query`, `chosen_inline_result`. Исправление: `/webhookfix`.
- **Группа «отвалилась» после включения тем:** напиши `/connect` в группе ещё раз.
- **Кружок не получается:** в логах ищи `ffmpeg-static не загрузился`, `makeCircle`, `sendVideoNote`. Чаще всего нет пакета или `includeFiles` в `vercel.json`, либо ролик слишком тяжёлый: попробуй короче или в 480p.
- **Битки и BPM не работают:** проверь `MP3_WORKER_URL` и `MP3_WORKER_SECRET` и логи воркера (`mp3 worker HTTP ...` в логах Vercel).
- **Cron не срабатывает:** задай `CRON_SECRET`; состояние в админке → Система → «Напоминания и cron» (кнопка «Проверить сейчас»).
- **Значок отличается от ожидаемого:** в логах `Emoji using animated alternatives` значит, что подобран другой анимированный значок.
