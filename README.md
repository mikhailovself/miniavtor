# Бот-секретарь для Telegram

Бот для заметок на несколько человек. Каждый пользователь подключает **свою** группу с топиками. Пишешь боту в личку что угодно, нейросеть выбирает подходящий топик твоей группы, оформляет заметку и публикует её туда.

У каждого пользователя свои: группа, топики, подсказки, запасной топик, стиль и часовой пояс. Ключи нейросетей общие (твои), поэтому есть дневной лимит на человека.

## Как пользоваться (для всех)

Вся инструкция есть в самом боте: `/start`, затем кнопка «➕ Подключить группу». Коротко:

1. Создай группу в Telegram и включи в ней **Темы** (настройки группы → Темы). Сделай это *до* добавления бота: при включении тем у группы меняется внутренний номер.
2. Создай топики под свои заметки: «Покупки», «Идеи», «Фильмы», «Долги». Названия любые, бот выбирает по смыслу.
3. Добавь бота в группу и сделай его **админом** (иначе он не видит сообщения в топиках). Кнопка «Добавить бота в группу» в боте делает это за пару нажатий.
4. В группе напиши `/connect`. Подключить может только админ группы.
5. В каждом нужном топике напиши любое сообщение или `/ids` (один раз на топик). Новые топики бот подхватывает сам.
6. Вернись в личку с ботом и пиши заметки.

В группу можно добавить других людей: они будут видеть заметки. Настройки топиков меняет только тот, кто подключил группу. Одна группа на одного пользователя: если подключить другую, старая отвяжется.

## Меню (в личке)

Открывается по `/start`, `/menu` или кнопке «📋 Меню».
- 📂 Мои топики: список, по нажатию на топик настройки (✏️ подсказка для бота, ⭐ сделать запасным, 🧪 проверить связь, 🗑 забыть)
- ⭐ Запасной топик: куда падает то, что никуда не подошло
- ➕ Подключить группу / 🔌 Моя группа: инструкция и отключение группы
- ⚙️ Настройки: стиль ответов, часовой пояс, удаление своих данных
- ❓ Помощь, ✍️ Автор бота

### Стили
Бот общается со всеми в своём фирменном стиле, как будто пользователь переписывается с автором:
- 🤪 **Мини.автор** (по умолчанию у всех): коротко, по-свойски, с редким матом и подъёбами. Манера выведена из реальной переписки автора (длина реплик, запятые и точки, любимые слова, как часто мат, смех и смайлы), а не придумана. Правится в `STYLE_PROMPTS.vlad`.
- 😎 **Дружеский**: разговорно и коротко, без мата.
- 🙂 **Обычный**: аккуратно и по делу, без мата.

Два последних варианта необязательные: человек может переключить их в «⚙️ Настройки», если фирменный стиль не нравится. Точность не страдает ни в одном стиле: имена, суммы, даты и ссылки бот переносит без искажений.

### Часовой пояс
Нужен, чтобы бот правильно понимал «завтра» и «в пятницу». Кнопки в настройках или команда `/tz Europe/Helsinki`. По умолчанию Москва.

## Команды

В личке: `/menu`, `/topics`, `/connect`, `/settings`, `/tz`, `/help`, `/author`, `/cancel`, `/deleteme`.

В группе (в нужном топике, только у того, кто подключил группу):
- `/connect`: подключить группу (может админ группы)
- `/ids`: запомнить топик
- `/desc текст`: подсказка для топика
- `/default`: сделать топик запасным
- `/forget`: забыть топик
- `/disconnect`: отключить группу

Только для `OWNER_ID` в личке: `/stats` (сколько пользователей), `/ban 123456789`, `/unban 123456789`.

## Запуск по шагам (для владельца бота)

1. **Бот.** @BotFather → `/newbot` → токен. Чтобы кнопка «Добавить бота в группу» работала, в @BotFather можно ещё включить `/setjoingroups` → Enable (по умолчанию включено).
2. **GitHub + Vercel.** Залей файлы в репозиторий (`api/webhook.ts` лежит в папке `api`), подключи к Vercel.
3. **Переменные** (Settings → Environment Variables):
   - обязательные: `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET`, `GEMINI_API_KEY`, `GEMINI_MODEL`, `OWNER_ID`
   - необязательные: `DAILY_LIMIT` (сообщений к нейросети на человека в сутки, по умолчанию 60, `0` = без лимита), `BOT_USERNAME` (юзернейм бота без @, иначе бот узнает его сам)
4. **База.** В проекте Vercel вкладка **Storage** → Upstash Redis (бесплатный план) → привяжи к проекту. Без базы бот не работает: в ней хранятся пользователи, группы и топики.
5. **Redeploy.**
6. **Вебхук.** Открой в браузере:
   `https://api.telegram.org/botТОКЕН/setWebhook?url=https://ТВОЙ-ПРОЕКТ.vercel.app/api/webhook&secret_token=СЕКРЕТ`
   Если задаёшь `allowed_updates`, добавь в список `message`, `callback_query` и `my_chat_member` (по умолчанию ограничений нет).
7. **Старт.** Напиши боту в личку `/start`. Дальше бот сам ведёт по инструкции.

### Если ты обновляешься со старой версии (один пользователь)
Ничего делать не нужно. При первом сообщении от `OWNER_ID` бот один раз переносит твою группу, топики, подсказки и запасной топик (старые ключи `tg:group`, `tg:topics`, `tg:desc`, `tg:default`) в новую схему. Переменная `GROUP_CHAT_ID` нужна только если группа не успела запомниться в базе, потом её можно удалить.

## Лимиты и защита
- Дневной лимит на человека (`DAILY_LIMIT`), счётчик по UTC. У владельца лимита нет. Считаются только сообщения, дошедшие до нейросети: меню, команды и инструкции бесплатны.
- Пока группа не подключена или топики не запомнены, бот не обращается к нейросети, а показывает инструкцию.
- Если бот открыт всем, а ключи твои, следи за расходом. Нежелательного человека можно заблокировать: `/ban его_id`.
- Группу подключает только её админ, и одну группу нельзя подключить к двум пользователям.
- Каждый пользователь может сам удалить свои данные: `/deleteme` или «⚙️ Настройки» → «🗑 Удалить мои данные». Заметки в самой группе при этом остаются.
- В базе хранятся: id пользователя, настройки, id группы, названия топиков и подсказки, последние 10 реплик диалога на сутки. Сами заметки бот хранит только в Telegram, в твоей группе.

## Запасные нейронки (автопереключение)
Основная модель Gemini (`GEMINI_API_KEY`, `GEMINI_MODEL`). Если она упала (лимит 429, модель отключили, таймаут), бот сам пробует следующую. Запасных можно до трёх, любой API в формате OpenAI (Groq, Mistral, Cerebras, OpenRouter, DeepSeek и другие). Для каждой задай в Vercel четыре переменные, где N это 2, 3 или 4:
- `LLMN_NAME`: любое имя, например `Groq`
- `LLMN_BASE_URL`: например `https://api.groq.com/openai/v1`
- `LLMN_API_KEY`: ключ
- `LLMN_MODEL`: название модели из списка провайдера (должна уметь tool calling)

Порядок: Gemini, потом 2, 3, 4. Упавшего бот на время откладывает в Redis (лимит 5 минут, неверный ключ или модель час, прочие ошибки минуту), чтобы не ждать зря. Какая именно модель ответила, пользователю не показывается. Если упали все, пользователю приходит «нейросети недоступны, попробуй через пару минут», а тебе (`OWNER_ID`) в личку подробности по каждой модели (не чаще раза в 10 минут).

## Как поменять оформление
Правь `buildSystemPrompt` и `STYLE_PROMPTS` в `api/webhook.ts`. Общие правила выбора топика и оформления заметки в `buildSystemPrompt`, манера речи для каждого стиля в `STYLE_PROMPTS`.

## Если что-то не работает
- Логи: Vercel → проект → Logs.
- Вебхук: `https://api.telegram.org/botТОКЕН/getWebhookInfo` (поле `last_error_message`).
- Бот молчит в личке: проверь базу (Storage → Upstash Redis) и переменные, потом Redeploy. Если молчит только у тебя, проверь `OWNER_ID` и не забанил ли ты сам себя.
- `/connect` в группе не отвечает: проверь, что бот добавлен в группу и является админом, а в группе включены темы.
- «Не вижу сообщения в топиках»: бот должен быть админом группы.
- Бот не запоминает топики: тот, кто подключил группу, должен написать в топике любое сообщение или `/ids`.
- Кнопки не нажимаются: проверь в `getWebhookInfo`, что в `allowed_updates` нет ограничений.
- Группа «отвалилась» после включения тем: напиши `/connect` в группе ещё раз.
