# Бот-секретарь для Telegram

Пишешь боту в личку что угодно, Gemini выбирает подходящий топик твоей группы из ЛЮБОГО числа топиков, красиво оформляет и постит туда.

## Как бот узнаёт топики
Бот запоминает группу и топики (названия читает из Telegram) и хранит их в бесплатной базе Upstash Redis.
Топиков может быть сколько угодно, названия любые. Бот выбирает по смыслу названия.
Чтобы бот узнал топик, зайди в него и напиши `/ids` (один раз). Новые топики бот подхватывает сам.

## Меню
В личке с ботом есть кнопка «📋 Меню» внизу и inline-кнопки в сообщениях:
- 📂 Мои топики: список, по нажатию на топик настройки
  - ✏️ Подсказка для бота (что сюда класть), 🧹 убрать подсказку
  - ⭐ Сделать запасным
  - 🧪 Проверить связь (бот пришлёт тестовое сообщение в топик)
  - 🗑 Забыть
- ⭐ Запасной топик: куда падает то, что никуда не подошло
- ➕ Добавить топик: инструкция
- ❓ Помощь

Меню открывается по `/start`, `/menu` или кнопке «📋 Меню».

## Команды в группе (только владелец, в нужном топике)
Ботам Telegram не видно топики заранее, поэтому в группе работают команды:
- `/ids`: запомнить топик.
- `/desc текст`: подсказка для топика.
- `/default`: сделать топик запасным.
- `/forget`: забыть топик.

## Запуск по шагам

1. **Бот.** @BotFather → `/newbot` → токен. Добавь бота в группу **админом** (иначе он не видит сообщения).
2. **GitHub + Vercel.** Залей файлы в репозиторий (`api/webhook.ts` лежит в папке `api`), подключи к Vercel.
3. **Переменные** (Settings → Environment Variables): `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET`, `GEMINI_API_KEY`, `GEMINI_MODEL`, `OWNER_ID`.
4. **База.** В проекте Vercel вкладка **Storage** → Upstash Redis (бесплатный план) → привяжи к проекту.
5. **Redeploy.**
6. **Вебхук.** Открой в браузере:
   `https://api.telegram.org/botТОКЕН/setWebhook?url=https://ТВОЙ-ПРОЕКТ.vercel.app/api/webhook&secret_token=СЕКРЕТ`
7. **Меню.** Напиши боту в личку `/start`.
8. **Обучи бота.** В каждом нужном топике группы напиши `/ids`.

## Запасные нейронки (автопереключение)
Основная модель Gemini (`GEMINI_API_KEY`, `GEMINI_MODEL`). Если она упала (лимит 429, модель отключили, таймаут), бот сам пробует следующую. Запасных можно до трёх, любой API в формате OpenAI (Groq, Mistral, Cerebras, OpenRouter, DeepSeek и другие). Для каждой задай в Vercel четыре переменные, где N это 2, 3 или 4:
- `LLMN_NAME`: любое имя, например `Groq`
- `LLMN_BASE_URL`: например `https://api.groq.com/openai/v1`
- `LLMN_API_KEY`: ключ
- `LLMN_MODEL`: название модели из списка провайдера (должна уметь tool calling)

Порядок: Gemini, потом 2, 3, 4. Упавшего бот на время откладывает в Redis (лимит 5 минут, неверный ключ или модель час, прочие ошибки минуту), чтобы не ждать зря. Какая именно модель ответила, пользователю не показывается (смотри в Vercel Logs, если упала основная). Если упали все, бот напишет в чат, что именно сломалось у каждого.

## Как поменять оформление
Правь `buildSystemPrompt` в `api/webhook.ts`.

## Если что-то не работает
- Логи: Vercel → проект → Logs.
- Вебхук: `https://api.telegram.org/botТОКЕН/getWebhookInfo` (поле `last_error_message`).
- Бот молчит в личке: проверь `OWNER_ID`.
- Кнопки не нажимаются: проверь в `getWebhookInfo`, что в `allowed_updates` нет ограничений (по умолчанию их нет).
- Бот не запоминает топики: он должен быть админом группы, в Vercel должна быть подключена база.
