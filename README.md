# Бот-секретарь для Telegram

Пишешь боту в личку что угодно, Gemini разбирает, к какой теме это относится, красиво оформляет и постит в нужный топик твоей группы.

Темы: 🎬 Кино, 💸 Долги, 🎧 Идеи для треков, ✅ ТТД, 📝 Заметки (всё остальное).

## Как бот узнаёт группу и топики
Бот сам запоминает твою группу и топики (по названию) и хранит их в бесплатной базе Upstash Redis.
Тема определяется по словам в названии топика: «Кино», «Долги», «Идеи для треков», «ТТД», «Заметки» и похожие.
Новые топики он подхватывает сам, ничего вписывать в Vercel не нужно.

## Запуск по шагам

1. **Бот.** @BotFather → `/newbot` → токен. Добавь бота в группу **админом** (иначе он не видит сообщения).
2. **Группа.** Включи «Темы» и создай топики: Кино, Долги, Идеи для треков, ТТД, Заметки.
3. **GitHub + Vercel.** Залей файлы в репозиторий (`api/webhook.ts` лежит в папке `api`), подключи к Vercel.
4. **Переменные** (Settings → Environment Variables): `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET`, `GEMINI_API_KEY`, `GEMINI_MODEL`, `OWNER_ID`.
5. **База.** В проекте Vercel открой вкладку **Storage** → создай/подключи **Upstash Redis** (бесплатный план) → привяжи к проекту. Vercel сам добавит нужные переменные.
6. **Redeploy** (Deployments → три точки → Redeploy).
7. **Вебхук.** Открой в браузере:
   `https://api.telegram.org/botТОКЕН/setWebhook?url=https://ТВОЙ-ПРОЕКТ.vercel.app/api/webhook&secret_token=СЕКРЕТ`
8. **Обучи бота.** В каждом топике группы напиши `/ids`. Бот ответит, что запомнил топик и к какой теме его привязал.
9. **Проверка.** Напиши боту в личку `/topics`: увидишь, что куда привязано.

## Команды
В личке:
- `/topics`: показать группу и привязки тем к топикам.
- любой текст: бот оформит и разложит по топикам.

В группе (только для тебя):
- `/ids`: запомнить топик, где написал.
- `/bind тема`: привязать топик вручную. Темы: `movies`, `debts`, `tracks`, `ttd`, `other`. Нужно, если название топика необычное.

## Как поменять темы
- Названия и эмодзи: `TOPIC_META` в `api/webhook.ts`.
- По каким словам бот узнаёт топик: `KEYWORDS`.
- Как оформлять заметки: `SYSTEM_PROMPT`.

## Если что-то не работает
- Логи: Vercel → проект → Logs.
- Вебхук: `https://api.telegram.org/botТОКЕН/getWebhookInfo` (поле `last_error_message`).
- Бот молчит в личке: проверь `OWNER_ID`.
- Бот не запоминает топики: он должен быть админом группы, а в Vercel должна быть подключена база.
