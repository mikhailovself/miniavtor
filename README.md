# Бот-секретарь для Telegram

Пишешь боту в личку что угодно, Gemini выбирает подходящий топик твоей группы из ЛЮБОГО числа топиков, красиво оформляет и постит туда.

## Как бот узнаёт топики
Бот запоминает группу и топики (названия читает из Telegram) и хранит их в бесплатной базе Upstash Redis.
Топиков может быть сколько угодно, названия любые. Бот выбирает по смыслу названия.
Чтобы бот узнал топик, зайди в него и напиши `/ids` (один раз). Новые топики бот подхватывает сам.

## Запуск по шагам

1. **Бот.** @BotFather → `/newbot` → токен. Добавь бота в группу **админом** (иначе он не видит сообщения).
2. **GitHub + Vercel.** Залей файлы в репозиторий (`api/webhook.ts` лежит в папке `api`), подключи к Vercel.
3. **Переменные** (Settings → Environment Variables): `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET`, `GEMINI_API_KEY`, `GEMINI_MODEL`, `OWNER_ID`.
4. **База.** В проекте Vercel вкладка **Storage** → Upstash Redis (бесплатный план) → привяжи к проекту.
5. **Redeploy.**
6. **Вебхук.** Открой в браузере:
   `https://api.telegram.org/botТОКЕН/setWebhook?url=https://ТВОЙ-ПРОЕКТ.vercel.app/api/webhook&secret_token=СЕКРЕТ`
7. **Обучи бота.** В каждом нужном топике группы напиши `/ids`.
8. В личке боту: `/topics` покажет, что он знает.

## Команды
В личке:
- `/topics`: список известных топиков.
- любой текст: бот оформит и положит в подходящий топик.

В группе, в нужном топике (только владелец):
- `/ids`: запомнить топик.
- `/desc текст`: подсказать боту, что сюда класть. Полезно для неочевидных названий вроде «СОХРЫ СООБЩЕНИЙ».
- `/default`: сделать топик запасным (куда класть то, что никуда не подошло). Топик с названием «Заметки» или «Разное» становится запасным сам.
- `/forget`: забыть топик.

## Как поменять оформление
Правь `buildSystemPrompt` в `api/webhook.ts`.

## Если что-то не работает
- Логи: Vercel → проект → Logs.
- Вебхук: `https://api.telegram.org/botТОКЕН/getWebhookInfo` (поле `last_error_message`).
- Бот молчит в личке: проверь `OWNER_ID`.
- Бот не запоминает топики: он должен быть админом группы, в Vercel должна быть подключена база.
