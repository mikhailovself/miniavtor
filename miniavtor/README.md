# Бот-секретарь для Telegram

Пишешь боту в личку что угодно, Claude разбирает, в какую тему это относится, красиво оформляет и постит в нужный топик твоей группы.

Темы: 🎬 Кино, 💸 Долги, 🎧 Идеи для треков, ✅ ТТД, 📝 Заметки (всё остальное).

## Запуск по шагам

### 1. Бот
1. В Telegram открой @BotFather, команда `/newbot`, получи токен.
2. Добавь бота в свою группу и сделай админом (право писать сообщения).
3. Включи у группы «Темы» и создай топики: Кино, Долги, Идеи для треков, ТТД, Заметки.

### 2. Свои id
- Свой user id: напиши @userinfobot, он ответит числом. Это `OWNER_ID`.
- Id группы и топиков узнаем после деплоя (шаг 5).

### 3. Репозиторий и Vercel
1. Залей эту папку в новый репозиторий на GitHub.
2. На vercel.com: Add New → Project → выбери репозиторий → Deploy.
3. В Settings → Environment Variables добавь все переменные из `.env.example`.
   Пока `GROUP_CHAT_ID` и `TOPICS` можно оставить с нулями.
4. Сделай Redeploy, чтобы переменные подхватились.

### 4. Подключи вебхук
Открой в браузере (подставь свои значения):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<твой-проект>.vercel.app/api/webhook&secret_token=<WEBHOOK_SECRET>
```

Должно вернуться `{"ok":true,...}`.

### 5. Узнай id группы и топиков
Зайди в группу, в каждом топике напиши `/ids`. Бот ответит:

```
chat_id: -1001234567890
thread_id: 5
```

Если топик «Заметки» это общий топик (General), у него `thread_id` может быть пустым. Тогда просто создай отдельный топик.

Впиши числа в Environment Variables на Vercel:

```
GROUP_CHAT_ID=-1001234567890
TOPICS={"movies":5,"debts":8,"tracks":11,"ttd":14,"other":2}
```

Redeploy.

### 6. Пользуйся
Напиши боту в личку, например:

> вася должен 3000 за билеты, надо глянуть Субстанцию, купить хлеб завтра и идея для трека: медленный бит и семпл дождя

Бот разложит это на 4 заметки по нужным топикам и ответит, что записал.

## Как поменять темы
- Названия и эмодзи: `TOPIC_META` в `api/webhook.ts`.
- Новая тема: добавь ключ в `TopicKey`, в `TOPIC_META`, в `enum` инструмента, в описание тем в `SYSTEM_PROMPT` и в `TOPICS`.
- Как оформлять заметки: правь `SYSTEM_PROMPT`.

## Если что-то не работает
- Логи: Vercel → проект → Logs.
- Проверь вебхук: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` (там видно последнюю ошибку).
- Бот молчит в личке: проверь `OWNER_ID`.
- Не постит в группу: бот должен быть админом, а `GROUP_CHAT_ID` начинаться с `-100`.
